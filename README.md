# practica-sql-ventas
# Práctica SQL: Análisis de ventas de tecnología

## Descripción

Este proyecto consiste en una práctica de SQL para explorar y analizar
una tabla de ventas de productos tecnológicos.

## Consultas realizadas

1. Selección de productos y precios con orden alfabético.
2. Filtrado de ventas de Colombia con precios superiores a 500.
3. Identificación de registros con categoría NULL.
4. Cálculo de ingresos totales por categoría.
5. Uso de HAVING para filtrar categorías con ingresos superiores a 10.000.

## Archivos

- `consultas_ventas.sql`: contiene la creación de la tabla,
  los datos ficticios de prueba y las cinco consultas SQL.

## Tecnologías

- SQL
- SQLite
- Google Colab y Python para ejecutar y verificar las consultas.

## Objetivo

Practicar la selección, el filtrado, la búsqueda de valores nulos,
la agregación de datos y el uso de GROUP BY y HAVING.
